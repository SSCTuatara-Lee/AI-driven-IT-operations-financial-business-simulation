# 下游通道不可用与高延迟

版本：1.0；适用：本项目模拟通道。

DEPENDENCY_UNAVAILABLE 表示本次请求在进入记账前连接下游失败；DEPENDENCY_SLOW 表示观测到下游调用耗时升高。

先按 trace_id 检查调用时间线，区分请求未进入记账阶段、业务拒绝与提交后响应失败。查看相同时间窗口的错误率和延迟分布，并对比下游健康、网络及配置变更。

仅凭一条连接错误不能确认是 DNS、网络或服务进程故障，需额外证据。避免无限重试；重试必须保留原幂等键与请求内容。

本项目的应用故障模拟可在演练页面停止，到期自动不再作用于新请求。停止后重新发送模拟交易并执行对账，确认交易路径与账务恢复。
